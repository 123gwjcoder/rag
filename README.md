# RAG 知识库问答系统

一个基于检索增强生成（RAG）的本地知识库问答系统。

## 功能
- PDF/文档解析与分块
- Embedding 向量化 + 向量检索
- 混合检索（BM25 + 向量）+ Rerank
- FastAPI 接口，支持流式输出与引用溯源

## 目录结构
- `src/` 核心代码
- `data/` 知识库原始文档
- `eval/` 评测集与评测脚本
- `docs/` 学习笔记
- `outputs/` 输出结果
